
RailAid
=======
AI-Powered Ferry Assistance and Passenger Support System

RailAid is a full-stack ferry assistance platform that helps passengers book support services such as wheelchair assistance, luggage handling, and mobility assistance. The system uses Machine Learning to recommend suitable services, estimate waiting times, and improve passenger experience.

Tech Stack:
- React.js
- Node.js
- Express.js
- MongoDB
- Flask
- Machine Learning
Health checks:

- Backend: `/api/health`
- ML API: `/health`
- Chatbot API: `/health`
