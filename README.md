# RailAid

## AI-Powered Ferry Assistance and Passenger Support System

RailAid is a full-stack ferry assistance platform designed to improve the travel experience of ferry passengers by providing intelligent support services such as wheelchair assistance, luggage handling, mobility assistance, and real-time booking management.

The system integrates Machine Learning to recommend suitable assistance services, estimate waiting times, and optimize staff allocation based on passenger requirements.

---

## Features

* Passenger Registration and Authentication
* Ferry Assistance Booking System
* Wheelchair Assistance Requests
* Luggage Handling Requests
* Mobility Assistance Services
* Real-Time Booking Status Tracking
* Driver/Staff Assignment System
* ML-Based Service Recommendations
* Wait Time Prediction
* Interactive Chatbot Support
* Admin Dashboard
* Staff Dashboard
* Booking History Management

## System Architecture

Passenger → React Frontend → Express Backend → MongoDB Database

Passenger Request → ML Service (Flask + Random Forest) → Service Recommendation & Wait Time Prediction

Passenger ↔ Chatbot Service

Admin/Staff Dashboard ↔ Backend APIs ↔ Database
